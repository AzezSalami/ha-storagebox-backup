# Remote Backup (Home Assistant add-on)

Encrypted, versioned backups of Home Assistant to Hetzner Storage Box, Hostinger, any SFTP/SSH server,
S3-compatible storage or any restic backend, with a web UI.

Add this repository under **Settings > Add-ons > Add-on Store > ... > Repositories**,
or copy `storagebox_backup/` into `/addons/` on your HA OS box (via Samba) to install it as a local add-on.
See `storagebox_backup/DOCS.md` for usage.
